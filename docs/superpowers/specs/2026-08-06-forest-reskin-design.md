# gyeot 숲 리스킨 디자인 (1단계: 배경 + 디폴트 동물)

날짜: 2026-08-06
상태: 사용자 승인된 접근안 A 기반

## 목표

gyeot 데스크탑 캐릭터 앱을 SOOP(숲) 브랜드에 맞춰 리스킨한다.
이번 단계는 **배경과 캐릭터 교체만** 다룬다. 동물 선택 UI는 다음 단계다.

아트 디렉션: **활발하고 따뜻한 숲**. 밝은 초록·따뜻한 앰버·햇살 노랑 중심의
파스텔 숲. 텍스트 가독성을 해치지 않는 밝은 톤을 유지한다.

## 범위

### 포함

1. **`ForestCharacter` 컴포넌트 신규** (`src/components/ForestCharacter.tsx`)
   - 기존 `DeskCharacter`를 완전히 대체한다.
   - `species` prop으로 동물 지정: `bear`(곰), `rabbit`(토끼), `mole`(두더지),
     `bird`(새), `fox`(여우), `squirrel`(다람쥐) — 6종.
   - 각 동물은 현재 캐릭터와 같은 플랫 벡터 스타일의 인라인 SVG로 그린다.
     동물별 자연색 팔레트를 내장한다(예: 곰=갈색, 여우=주황).
   - **종 → 렌더러 레지스트리** 구조: 종마다 SVG 그리기 함수를 등록한다.
     나중에 이미지 에셋이 준비되면 레지스트리에서 해당 종의 렌더러만
     `<img>` 기반으로 교체한다. 호출부(App.tsx)는 바뀌지 않는다.
   - 기존 `active`(작업 중/자리 비움 애니메이션), `emote` prop 동작 유지.
   - 기존 `tone`/`variant` prop은 `species`로 대체된다.

2. **내 캐릭터: 미지정 시 랜덤, 지정 시 고정**
   - 동물을 지정하지 않았으면 앱 실행 시 6종 중 하나를 랜덤으로 뽑는다
     (실행 중 유지, 재실행 시 다시 뽑음).
   - 동물을 지정하면 `localStorage("gyeot:species")`에 저장하고, 그때부터는
     항상 그 동물이 뜬다. "랜덤" 선택지로 지정을 해제할 수 있다.
   - 룸메이트와 같은 종이 나와도 허용한다(중복 회피 로직 없음).

3. **최소 동물 선택 UI (이번 단계 포함)**
   - 기존 "내 소개" 다이얼로그(풀 모드)에 동물 선택 줄을 추가한다:
     동물 6종 + "랜덤" 버튼. 클릭 즉시 반영·저장된다.
   - 전용 온보딩/선택 화면은 다음 단계에서 다룬다.

4. **룸메이트 동물 = 각자의 선택값**
   - 룸메이트 캐릭터는 "그 사람이 고른 동물"을 그대로 보여준다.
     데이터 모델에서 `species`는 룸메이트별 필드다.
   - 지금은 온라인 연결 전이므로 미리보기 룸메이트 6명에게 서로 다른
     동물을 고정값으로 넣는다. 온라인 연결 시 서버에서 받은 값으로
     대체된다(이번 단계에서는 서버 연동 없음).

5. **숲 배경 및 전체 톤**
   - 풀 모드: 하늘(연한 햇살빛) → 나무 실루엣(층진 초록) → 땅(따뜻한 흙색)
     3단 레이어. CSS 그라데이션 + App.css 내 인라인 SVG data URI로 구현한다
     (별도 배경 컴포넌트를 만들지 않는다). 외부 리소스는 쓰지 않는다.
   - 컴팩트 위젯: 은은한 숲 그라데이션 + 잎사귀 포인트.
   - 헤더·카드·버튼·필 등 UI 전반의 색을 따뜻한 숲 팔레트로 조정한다
     (기존 보라/파스텔 → 초록/앰버 계열).
   - 자리(책상) 그리드 구조는 유지하되 책상을 나무 그루터기 톤으로 색만
     조정한다.

### 제외 (다음 단계)

- 전용 동물 선택 화면/온보딩(최소 선택 UI는 위 3번으로 이번 단계 포함)
- 숲 풍경 전면 재구성(자리 그리드 제거, 씬 배치)
- 이미지 에셋 적용(사용자가 에셋을 주면 레지스트리에서 교체)

## 바뀌지 않는 것

세션 감지(Rust)와 폴링, 이모티콘, 한 줄 소개 말풍선, 투명도 슬라이더,
창 모드 전환(컴팩트/풀), 창 드래그.

## 팔레트 (기준값)

- 햇살: `#FFE9A8` / 밝은 잎: `#A8D98A` / 짙은 잎: `#5E9C5B`
- 흙·나무: `#B98A5F` / 그루터기: `#8A6242` / 크림 배경: `#FBF6E9`
- 포인트(앰버): `#F0A848` / 텍스트: 기존 대비 유지(진한 갈색·녹색 계열)

정확한 값은 구현 중 가독성 기준으로 미세 조정 가능하다.
