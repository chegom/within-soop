# 곁 (Gyeot)

혼자 Codex나 Claude Code와 작업할 때, 다른 사람들과 조용히 같은 방에 있는 감각을 주는 Mac·Windows 데스크톱 앱입니다.

## 현재 구현된 첫 조각

- Codex·Claude Code 프로세스를 로컬에서 4초마다 감지
- 실제 프로세스 시작 시간을 기준으로 현재 연속 세션 시간 표시
- 최대 10명이 앉는 고정형 공유 책상 UI
- `390×220` 축소 위젯과 `920×700` 관리 화면 전환
- 축소 시 현재 모니터 오른쪽 아래 배치, 항상 위 표시, 드래그 이동
- macOS 전체 화면 앱과 다른 Space에서도 축소 위젯 표시
- 마지막으로 선택한 창 모드를 다음 실행에도 유지
- 한 줄 소개 편집 및 로컬 저장
- 내 캐릭터 위에 잠깐 나타나는 이모티콘
- 브라우저에서 확인할 수 있는 명시적인 프로토타입 방

프로세스 이름과 실행 경로는 상태 판별에만 사용하며 앱 밖으로 전송하지 않습니다. 프롬프트, 터미널 내용, 파일 경로는 읽지 않습니다.

현재 방의 다른 캐릭터는 온라인 서버를 붙이기 전의 **화면 미리보기 데이터**입니다. 실제 전체 접속자, 친구 초대, 파티 동기화는 다음 단계에서 연결합니다.

## 실행

```bash
npm install
npm run tauri dev
```

프런트엔드 화면만 확인하려면:

```bash
npm run dev
```

## 확인 명령

```bash
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
cargo check --manifest-path src-tauri/Cargo.toml
```
